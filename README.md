# 🌦️ Weather Forecasting App

A simple and responsive weather application that displays current weather information for any city using HTML, CSS, and JavaScript.

## 🔍 Features

- 🌍 Search for any city worldwide
- 🌡️ Display current temperature, weather conditions, humidity, and wind speed
- 🖼️ Dynamic background images based on weather conditions
- 📱 Responsive design for mobile and desktop devices

## 🛠️ Technologies Used

- **HTML5**: Structure of the application
- **CSS3**: Styling and layout
- **JavaScript (ES6)**: Fetching data and interactivity
- **[OpenWeatherMap API](https://openweathermap.org/api)**: Source of real-time weather data

## 🚀 Getting Started

### Prerequisites

- A modern web browser (e.g., Chrome, Firefox, Edge)
- An API key from [OpenWeatherMap](https://openweathermap.org/api)

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Yateesh12/wheather.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd wheather
   ```

3. **Open `index.html` in your web browser:**

   - You can double-click the `index.html` file
   - Or use a live server extension if you're using VS Code

4. **Insert your OpenWeatherMap API key:**

   - Open the JavaScript file (e.g., `script.js`)
   - Locate the line where the API key is defined:

     ```javascript
     const apiKey = "YOUR_API_KEY_HERE";
     ```

   - Replace `"YOUR_API_KEY_HERE"` with your actual API key
